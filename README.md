# Calculator

A simple, modern calculator built using HTML, CSS, and JavaScript.

## Features
- Basic arithmetic operations (+, −, ×, ÷)
- Decimal number support
- Division by zero error handling
- Previous calculation display
- Calculation history
- Light and dark themes
- Keyboard support
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Project Purpose
This project was created as part of a web development assignment to practice JavaScript functions, DOM manipulation, event handling, and CSS styling.
